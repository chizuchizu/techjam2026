Note

You do not need to install **PlatformIO Core** if you are going to use [PlatformIO IDE](https://docs.platformio.org/en/latest/integration/ide/pioide.html#pioide)
. **PlatformIO Core** is built into PlatformIO IDE and you will be able to use it within PlatformIO IDE Terminal. See instructions on how to open [PlatformIO Core CLI in PlatformIO IDE for VSCode](https://docs.platformio.org/en/latest/integration/ide/vscode.html#ide-vscode-pio-core-cli)
.

If you need **PlatformIO Core** outside PlatformIO IDE, please [Install Shell Commands](https://docs.platformio.org/en/latest/core/installation/shell-commands.html#piocore-install-shell-commands)
.
