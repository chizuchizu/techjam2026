1. Accuracy gate

Applied per output element: abs_err <= 0.002 OR rel_err <= 0.02, against the torch reference for the same seed. This section precedes the timings on purpose — a speedup measured at a different shape, or with a failing gate, is not a speedup.

A large max relative error alongside zero failures is expected, not a defect: the gate is a disjunction, so an element whose reference value sits near zero passes on the absolute term regardless of its ratio. Reporting both is what makes that visible instead of alarming.

2. What is being timed, and what the timing costs

One forward of the complete four-layer body. A warm-up forward runs first and is excluded. Host transfer of the 64 KB input and output is excluded on both sides.

Zones are timed with the free-running cycle counter at 1.0 ns, not the microsecond timer. That is not a refinement: at 1 us resolution the residual adds round to zero, and the implementation this replaced then dropped them with an if (d > 0) guard — so res1 was absent from the profile entirely and res2 reported 2 calls out of 12. Zones are now counted whether or not they register time, and any zone averaging under 20 ticks is flagged resolution-limited rather than reported as though exact.

analytic_exact means every call moves the same bytes. analytic_averaged means bytes vary with the causal row index and only the per-forward total is exact — the closed form is below. parent_only means the traffic is attributed to the zone's children, so counting it here would double it.

How each figure is derived — the point of keeping the model in the artifact rather than in someone's notes

quant — Each call is one tm_gemm_head_q15: it streams one head slice of a Q12 weight matrix, HD*D int16 = 32*128*2 = 8192 B from flash. 48 calls per forward = 4 layers x (4 V + 4 Q + 4 K) head projections. 48 x 8192 = 393,216 B, which is the 384 KB 'KB0' row of optimisations/20_profiling_memory_compute.md, here derived from a measured call count instead of assumed. SRAM term is the Q15 activation read, S*D int16 x 2 (read a16, write the head buffer).

oproj — One core5 output projection per layer over the full D x D Q12 matrix: 128*128*2 = 32,768 B of flash. 4 calls = 131,072 B. SRAM: read S*D int16 context + write S*D fp32.

f1 — First FFN GEMM, F x D Q12 = 128*128*2 = 32,768 B of flash per layer.

f2 — Second FFN GEMM, D x F Q12 = 32,768 B of flash per layer. Note gelu is measured inside this zone, so f2's exclusive time excludes the activation but its weight traffic is unaffected.

norm1 — LayerNorm reads S*D fp32 and writes S*D, 65,536 B each way. Flash term is the gain/bias pair, 2*D fp32 = 1,024 B.

norm2 — As norm1, on the post-attention residual.

final — The single trailing LayerNorm after the last layer.

attn_qk — Attention reads no weights - Q and K are activations already in SRAM. One call is one query row against the causal prefix, so bytes vary with the row index i and only the mean is meaningful: (S+1)/2 * HD * 2 = 64.5*32*2 = 4,128 B. Total over a forward is exact even though the per-call figure is an average, because the causal triangle S*(S+1)/2 is summed exactly. 2048 calls = 4 layers x 4 heads x 128 rows. Closed form: mean over i of (i+1)*HD*2 bytes = (S+1)/2 * HD * 2.

attn_pv — Same causal triangle as attn_qk, reading V rather than K. Closed form: mean over i of (i+1)*HD*2 bytes = (S+1)/2 * HD * 2.

attn_exp — The integer exp LUT is 513 int16 entries and stays resident; the traffic is the score row itself, (i+1) int16 on average (S+1)/2*2 = 129 B read plus the same written back. Closed form: mean over i of (i+1)*2 bytes of int16 LUT-indexed scores.

res1 — Residual add: two S*D reads plus one S*D write, 3 x 65,536 B.

res2 — As res1.

gelu — In-place over the S*F Q15 buffer: 32,768 B read + 32,768 B written. The LUT is 513 int16 and stays cache-resident.

qkv — qkv is a bracket around quant calls plus the attention dispatch; its own traffic is attributed to quant, so counting it again here would double-count.

attn — attn brackets attn_qk / attn_exp / attn_pv; traffic is attributed to those children.
